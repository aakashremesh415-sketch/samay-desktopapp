# Samay desktop app

Samay by Renocrew Solutions — desktop time tracker for Windows and macOS.

Download the latest version from [Releases](https://github.com/aakashremesh415-sketch/samay-desktopapp/releases/latest):

- **Windows:** `Samay-Setup-<version>.exe`
- **macOS:** `Samay-<version>.dmg`

After installing, sign in with your Samay account. The app updates itself when a new version is released.

This repository only hosts the installers; they are built and signed automatically from the private `rcs3` repo, and installed apps verify each update before installing it. See [SECURITY.md](SECURITY.md).
